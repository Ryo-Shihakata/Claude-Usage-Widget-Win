# Claude Usage Widget

Claude Code の使用量をデスクトップに**常時表示**するフローティングウィジェット（Windows / Electron）。

<img src="resources/icon.png" width="72" alt="icon" />

開発中いつでも、画面の片隅で「あと5時間枠・週間枠をどれだけ使えるか／今日どれだけ使ったか」を一目で確認できます。ターミナル風の窓（ドット付きヘッダ＋ステータスバー）に、マスコット **clawd**（コーラルのカニ）が常駐します。

---

## 表示される内容

ローカルの `~/.claude/projects/**/*.jsonl`（Claude Code のセッションログ）を集計し、半透明の小窓に表示します。

| パネル | 内容 |
| --- | --- |
| **利用枠（5時間 / 1週間 / 週(Fable) / 追加枠）** | Claude のレート制限に対応する枠の消費ゲージ（コーラル→黄→赤）。**既定でクラウド（公式 /usage）を使用**——claude.ai の利用率をそのまま表示。加えて **Fable/Mythos を使っていれば「週(Fable)」ゲージ**を表示（設定でON/OFF可）。公式 /usage が Fable 枠の値を返す場合はそれを優先して表示し、返さない場合は7日間の Fable トークン量から**ローカル集計で推定**したうえでラベルに **「（推定）」** を付けて区別する（例: `週(Fable)（推定）`）。未ログイン・取得失敗時は 5時間/1週間 も含めゲージ全体がローカル推定へ自動フォールバックする。 |
| **今日のトークン** | 今日のモデル別トークン（上位2モデル、Fable/Mythos含む）＋メッセージ数 / セッション数。 |
| **日毎グラフ** | 直近7日の日毎トークン使用量を棒グラフで表示（今日の棒だけ明るい／ホバーで値）。設定でON/OFF可。 |
| **推定コスト** | 公開単価（Opus/Sonnet/Haiku/**Fable/Mythos**）で換算した今日 / 7日の推定USD＋**各期間の合計トークン使用量**。サブスク利用では課金されないため**参考値**。 |
| **ステータスバー** | clawd マスコット＋現在のモード（☁ 公式 / ⌂ 推定）＋最終更新時刻。 |

> **重要**: クラウド（公式）モードは claude.ai の値をそのまま表示するため `/usage` コマンドと一致します。ログインしていない・通信できない場合は**ローカルログからの推定**に自動で切り替わります（この場合は公式値と完全一致しません）。ローカル推定時の基準値は設定で調整できます。

- **自動更新**: Claude Code が応答するたびに数秒で反映（ファイル監視＋30秒ごとの再集計）。
- **タスクバー（トレイ）表示**: ウィンドウを隠していても、タスクトレイのアイコンが**リングゲージ**で消費率を表示（色も連動）。ホバーで `5時間: X% / 1週間: Y%` のツールチップ。
- **クラウド既定**: 初回起動時は claude.ai へのログインを促されます。ログインするとアカウント全体の公式利用率を取得します（ローカルのみで完結させたい場合は設定でOFFにできます）。

## インストール（配布版を使う）

**[GitHub Releases](https://github.com/Ryo-Shihakata/Claude-Usage-Widget-Win/releases) から最新版をダウンロード**して、どちらかをダブルクリックするだけ。**Node.js は不要**です。

| ファイル | 使い方 |
| --- | --- |
| `Claude Usage Widget Setup x.y.z.exe`（インストーラ） | ダブルクリックでインストール。スタートメニュー＆デスクトップにショートカット、インストール後すぐ起動。管理者権限不要（ユーザー単位）。**自動アップデート対応**。 |
| `ClaudeUsageWidget-portable-x.y.z.exe`（ポータブル） | インストール不要。ダブルクリックでそのまま起動。USB や共有フォルダ向き（自動アップデートは無し）。 |

未署名のため初回は SmartScreen 警告が出ます →「詳細情報」→「実行」。

**自動起動はデフォルトでON**（OSログイン時に自動で立ち上がる）。不要ならトレイメニューまたは設定でOFFに。

### 自動アップデート

インストーラ版は起動時＋6時間ごとに GitHub Releases をチェックし、新しい版があればバックグラウンドでダウンロード→次回終了時に自動適用します（DL完了時にOS通知）。ポータブル版は対象外（手動で入れ替え）。

## 自分でビルドする / 開発する

前提: [Node.js](https://nodejs.org/) 20 以上（Windows 11）。

```bash
cd C:\dev\projects\Claude-Usage-Widget
npm install
npm run dev        # ウィジェットが起動（開発モード・ホットリロード）
```

配布ファイルを作る / GitHub Releases に公開する:

```bash
npm run package    # release/ に インストーラ(.exe) と ポータブル(.exe) を生成（ローカル）
GH_TOKEN=$(gh auth token) npm run release   # ビルドして GitHub Releases へ（下書き）
```

リリースの詳しい手順（バージョン採番・公開・自動アップデート配信・注意点）は **[RELEASING.md](RELEASING.md)** を参照。

> **GUI が必要です。** ヘッドレス環境や `ELECTRON_RUN_AS_NODE=1` が設定された環境では起動できません（通常のデスクトップなら問題ありません）。
> **ビルドには Windows の「開発者モード」推奨**（electron-builder の winCodeSign 展開がシンボリックリンク作成を伴うため）。

## 使い方

### ウィンドウ操作
- **移動**: ヘッダ（"claude@usage" の行）をドラッグ。位置は自動保存。
- **サイズ変更**: ウィンドウの端をドラッグしてリサイズ可能。サイズも自動保存されます。内容が収まらない場合は縦スクロールします。
- **⟳ ボタン**: 即時更新。
- **⚙ ボタン**: 設定パネルの開閉。

### 設定（⚙ または トレイメニュー）
- **5時間 基準 (Mtok)** / **1週間 基準 (Mtok)** / **週(Fable) 基準 (Mtok)**: ローカル推定時に各ゲージが 100% になるトークン数（百万単位）。公式の 5h/週間ゲージでは使われません（週(Fable) は公式 /usage が Fable 枠を返せばその値を使い、返さなければこの基準値でローカル推定＝「（推定）」表示になります）。
- **週(Fable) ゲージを表示** / **日毎グラフを表示** / **コスト表示**: 各パネルの表示/非表示。
- **OS起動時に自動起動**: ログイン時の自動起動（デフォルトON）。
- **公式 /usage（クラウド）を使う（デフォルトON）**: claude.ai のセッションCookieで公式の使用量（5時間枠・週間枠・追加枠の利用率）を取得し、利用枠を**公式実データ**に置き換えます（パネルに「☁ 公式 /usage」表示）。未ログインならパネル内の「claude.ai にログインして公式値を表示」ボタン、または設定/トレイの「claude.ai にログイン」から専用ウィンドウでログインしてください（ログイン情報は永続保存）。取得できない場合はローカル推定へ自動フォールバック（「⌂ 推定」表示）。⚠️ claude.ai の**非公開Web API**（`/api/organizations/{orgId}/usage`）に依存するため、仕様変更で動かなくなる可能性があります。

### システムトレイ
タスクトレイのアイコンを**右クリック**でメニュー、**左クリック**で表示/非表示。

| メニュー | 動作 |
| --- | --- |
| 表示 / 非表示 | ウィンドウの表示切替 |
| 常に最前面 | 他ウィンドウより手前に固定 |
| コスト表示 | コストパネルの表示切替 |
| OS起動時に自動起動 | ログイン時の自動起動切替 |
| 公式 /usage を使う | 公式実データ取得のON/OFF（ON時はログインを促す） |
| claude.ai にログイン | 公式 /usage 用のログインウィンドウを開く |
| 今すぐ更新 | 手動で再集計 |
| 終了 | アプリを終了 |

## 困ったとき

| 症状 | 対処 |
| --- | --- |
| 「Claude Code のデータが見つかりません」 | `~/.claude/projects/` が存在するか確認。別の場所なら環境変数 `CLAUDE_CONFIG_DIR` を設定。 |
| 数値が増えない | Claude Code を1ターン動かすと数秒で反映。されなければ ⟳ で手動更新。 |
| 利用枠が「⌂ 推定」のまま／体感と合わない | claude.ai に未ログインか取得失敗です。パネル内のログインボタン、またはトレイの「claude.ai にログイン」でログインすると「☁ 公式」に切り替わります。ローカル推定のままにする場合は「5時間 / 1週間 基準」を体感上限に合わせて調整。 |
| コストが実際の請求と違う | 公開単価ベースの**参考値**。サブスク利用では実課金は発生しません。 |
| ウィンドウが見当たらない | トレイアイコンを左クリックで再表示。「常に最前面」をオンに。 |
| （開発者のみ）OSログイン時に Electron のデモ画面が起動する | `npm run dev` を一度実行すると解消します（v0.3.0 で dev 実行時は自動起動登録を行わないよう修正済み）。直らない場合はタスクマネージャ→スタートアップで "Electron" を無効化してください。 |
| （開発者のみ）`npm run dev` でウィンドウが出ない／`Unable to move the cache: アクセスが拒否されました` | インストール版が常駐していると発生していた問題（userData と単一インスタンスロックの共有）。修正済み: dev は専用の userData（`%APPDATA%\claude-usage-widget-dev`）を使うため、インストール版と同時起動できます。dev では設定・claude.ai ログインがインストール版と共有されない点に注意。 |

```bash
npm run collect    # 集計ロジックを CLI で実行（Electron 不要、動作確認用。5時間/週間の両枠を出力）
npm run typecheck  # 型チェック
npm run build      # 本番ビルド（out/）
```

設計・アーキテクチャ・拡張方法・既知の制約は **[DESIGN.md](DESIGN.md)** を参照（実装の引き継ぎ用）。

単価は `src/main/usage/pricing.ts` に公開価格（2026-06時点、Opus/Sonnet/Haiku/Fable/Mythos）を定数化。価格改定時はこのファイルを更新してください。
