## v0.5.0 — 設定のトレイ即反映・内部整理・依存更新

### 修正
- **トレイで切り替えた設定がすぐウィジェットに反映されるように**: これまではトレイで「コスト表示」などを切り替えても、ウィジェットを開き直すまで表示が変わりませんでした
- トークンパネルで Mythos モデルの名前を `Mythos` と表示するように

### その他
- Electron 45 などへの依存更新（本番依存の既知の脆弱性を解消）
- 内部構造の整理（重複処理の共通化、公式 /usage 解析の分離、設定画面のコンポーネント化）とテストの追加。使用量の集計結果は v0.4.0 と同じです

インストール版は自動で更新されます（起動中にダウンロードし、次回終了時に適用）。
