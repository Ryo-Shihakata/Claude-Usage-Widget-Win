## 要件の解読（採用した前提）

| # | 要望 | 採用した解釈・方針 |
|---|---|---|
| 3 | 起動時に Electron デモ | **原因特定済み（高確度）**: `src/main/index.ts` が dev 実行でも `app.setLoginItemSettings({openAtLogin:true})` を無条件に呼ぶ（launchAtLogin 既定ON）。dev では `process.execPath` = `node_modules\electron\dist\electron.exe` なので、**素の electron.exe が Windows スタートアップに登録され、ログイン時に Electron デモ（welcome画面）が起動する**。修正: `app.isPackaged` でガードし、**dev では `setLoginItemSettings({openAtLogin:false})` を能動的に呼んで stale エントリを掃除**する（修正後に一度 `npm run dev` すれば registryが消える。手動なら タスクマネージャ→スタートアップ で "Electron" を無効化）。 |
| 4,5,2 | /usage と同じ・クラウド既定・利用統計 | 実体は同一要望。公式 /usage（claude.ai Cookie方式、実装済み `officialUsage.ts`）は**アカウント全体**（claude.ai チャット含む）の利用率を返すので「クラウドの利用統計」を兼ねる。対応: ①`DEFAULT_SETTINGS.useOfficialUsage` を **true** に ②CLI の /usage は「5h / 週(全モデル) / 週(Opus)」の3ゲージなので、レスポンスの**追加バケット（`seven_day_opus` 等）を防御的にパースして追加ゲージ表示**（キーは未検証なので寛容に: `five_hour`/`seven_day` 以外で `utilization` を持つキーを拾いラベル化）③未ログイン時は LimitPanel に「claude.ai未ログイン→推定表示」ヒント＋設定パネルにログインボタン（新IPC `claude:login` → `openClaudeLogin()`） |
| 6 | Fable 対応 | `pricing.ts` に `claude-fable-5` / `claude-mythos-5` を追加: **$10/$50 per MTok、cacheRead $1.00、cacheWrite(5m) $12.50**（claude-api スキルの公開価格）。`resolveRate()` の族名フォールバックに `fable`/`mythos` を追加（現状 null→コスト0円に化ける実バグ。ユーザーは Fable 使用中なので今日のコストが過少表示になっている）。`shortModel()` は fable 対応済み。 |

3. **クラウド既定＋追加バケット（#2,4,5）**:

## レッドチーム（計画への反映済み）

想定失敗3つ:
1. **公式レスポンスの実形状が未検証**（extras キー名は推測）→ 防御的パース＋取れなくても five_hour/seven_day だけで成立＋ローカルフォールバック維持。**実機で一度 JSON を目視すること**（`officialUsage.ts` に console.debug を一時追加するなど）。
2. **固定ウィンドウ高さと動的ゲージ数の不整合** → main 側 setBounds＋設定パネルのオーバーレイ化で吸収。
3. **ログイン項目の stale エントリが残存**（コード修正だけでは消えない）→ dev 起動時の能動 `openAtLogin:false` で自動掃除＋READMEに手動手順。

エッジケース: ①クラウド既定ONだが未ログイン→ローカル推定＋ヒント表示（無害に動く） ②`utilization` が 0..1 か 0..100 か→ 既存 `toLimit` が >1 なら /100 で両対応済み ③Cookie失効(401)→ null→フォールバック（実装済み） ④extras 0件→ 高さ BASE のまま。

より単純な設計の自問: extras を作らず既存2ゲージだけでも要件の大半は満たせるが、「/usageと同じ」に週Opus枠が含まれるため extras 採用。ただし**実形状確認までは五時間/週の2枠が確実に出ることを優先**。

## 既知の罠（このリポジトリ固有・実証済み）

- サンドボックスは `ELECTRON_RUN_AS_NODE=1` 強制 → **GUI 起動不可**。GUI検証は実機の人間に依頼する。
- `os.tmpdir()`（8.3短縮名）配下の chokidar 監視は libuv がクラッシュ → watcher テストはロングパス配下で。
- electron-vite の `externalizeDepsPlugin()` を外すと electron-updater がバンドルされ壊れる（設定済み・触らない）。
- `main` への直接 push は権限ブロック → ブランチ＋PR。コミット/push はユーザー指示があってから。
